# Portfolio — Leo Cabart, data analyst

Site publié sur **https://lcabart21.github.io**.

- `index.html` : page unique (HTML et CSS, sans dépendance JavaScript), générée par `build.py`.
- `assets/` : visuels des projets mis en avant.

Pour modifier le contenu, il faut éditer les données en tête de `build.py`, puis lancer :
```bash
python build.py index.html
```
